# TalkStep 영어회화 — 사용 · 배포 · 수익화 가이드

코딩을 몰라도 그대로 따라 할 수 있게 적었습니다.

---

## 1. 이 프로그램이 하는 일

| 기능 | 설명 |
|---|---|
| 3가지 회화 | 생활회화 · 비즈니스 · 여행회화 |
| 3단계 난이도 | 초급 · 중급 · 고급 (분야마다 단계별 2개 = 총 18개 대화, 대화마다 5턴) |
| 실제 대화처럼 | 상대방이 영어로 말하면 → 내가 영어로 답하고 → 다음 대사로 이어짐 |
| 한국어 교정 | 틀린 문법을 찾아 **한국어로 이유와 예시**를 보여 주고, 빠진 단어는 노란색으로 표시 |
| 듣기/말하기 | 🔊 상대 대사·모범답안을 원어민 발음으로 듣기 (천천히 / 조금 느리게 / 원어민 속도), 🎤 마이크로 말해서 입력 |
| 발음 코치 | 문장을 듣고 따라 말하면 단어별로 초록(정확)/빨강(안 들림) 표시 + 발음 점수, R/L·F/V·TH 같은 한국인 약점 교정, 연음·축약(gonna)·강세·억양 팁 |
| 기록 | 대화별 최고 점수, 별점, 연속 학습일 저장 |
| 모바일+PC | 같은 파일 하나가 휴대폰·태블릿·컴퓨터 화면에 맞게 바뀜. 휴대폰 홈 화면에 앱처럼 설치 가능 |

> 참고: 교정 기능은 **AI가 아니라 미리 만든 규칙**으로 동작합니다. 인터넷·API 요금 없이 무료로 돌아가는 대신, 모범답안과 많이 다른 자유로운 문장은 정확히 판단하지 못할 수 있습니다.

### 파일 구성

```
talkstep/
├─ index.html            ← 앱 본체 (화면, 대화 내용, 교정 규칙 전부 여기)
├─ manifest.webmanifest  ← 휴대폰에 "앱으로 설치"할 때 쓰는 정보
├─ sw.js                 ← 인터넷 없이도 열리게 해 주는 파일
├─ icon-192.png / icon-512.png  ← 앱 아이콘
├─ privacy.html          ← 개인정보처리방침 (앱스토어 등록 시 필요, 문의 이메일만 본인 것으로 수정)
└─ README.md             ← 지금 보고 있는 설명서
```

## 2. 내 컴퓨터에서 바로 실행하기 (1분)

1. `talkstep` 폴더를 내 컴퓨터에 내려받습니다.
2. `index.html` 파일을 **더블클릭**합니다. 크롬(Chrome)이나 엣지(Edge)로 열립니다.
3. 바로 학습할 수 있습니다.

> 이 방식에서는 "홈 화면에 설치" 기능만 빠지고, 나머지는 모두 동작합니다.
> 🎤 마이크 입력은 **크롬**에서 가장 잘 동작합니다.

## 2-1. 발음 코치 사용법

1. 대화 중 상대 대사 아래 **따라 말하기** 또는 피드백 카드의 **발음 연습** 버튼을 누릅니다.
2. 원어민 음성이 나옵니다. **굵은 단어는 강하게**, 나머지는 약하게 말하는 게 원어민 리듬입니다.
3. **눌러서 따라 말하기**를 누르고 문장을 말합니다. 말을 멈추면 자동으로 채점됩니다.
4. 빨간 단어를 누르면 그 단어만 천천히 들려줍니다. 아래 한국어 팁을 보고 다시 도전하세요.

> 발음 점수는 "음성인식이 내 말을 정확히 알아들었는지"를 기준으로 매깁니다. 원어민이 알아듣기 쉬운 발음인지를 확인하는 데 유용하지만, 발음기호 하나하나를 분석하는 전문 발음 평가는 아닙니다.

**더 원어민 같은 목소리로 듣는 법**: 오른쪽 위 ⚙ 설정에서 속도와 목소리를 고를 수 있습니다.
- 윈도우 PC: **엣지(Edge)** 브라우저로 열면 'Natural' 음성이 자동으로 선택됩니다.
- 아이폰: 설정 › 손쉬운 사용 › 음성 콘텐츠 › 음성 › 영어에서 **'향상된(Enhanced)'** 음성을 내려받으세요.
- 안드로이드: 크롬에서 'Google US English' 음성이 자동으로 선택됩니다.

## 3. 인터넷에 올려서 휴대폰으로도 쓰기 (무료, 약 5분)

인터넷 주소(URL)가 생기면 휴대폰에서도 열리고, 다른 사람에게 팔거나 공유할 수 있습니다.
가장 쉬운 방법인 **Netlify Drop**을 추천합니다.

### 방법 A. Netlify Drop (가장 쉬움)

1. 컴퓨터 브라우저에서 `https://app.netlify.com/drop` 에 들어갑니다.
2. 무료 회원가입을 합니다. 구글 계정으로 가입할 수 있습니다.
3. `talkstep` **폴더 전체**를 화면의 점선 상자 안으로 끌어다 놓습니다.
4. 몇 초 뒤 `https://무작위이름.netlify.app` 같은 주소가 생깁니다. 이게 내 앱 주소입니다.
5. 이름을 바꾸려면 **Site configuration → Change site name**에서 예를 들어 `talkstep-english`로 바꿉니다.
6. 내용을 고친 뒤에는 **Deploys** 메뉴에서 폴더를 다시 끌어다 놓으면 갱신됩니다.

### 방법 B. GitHub Pages (무료, 조금 더 단계가 많음)

1. `github.com`에 가입한 뒤 오른쪽 위 **+ → New repository**를 누르고, 이름을 `talkstep`으로 짓고, **Public**으로 만듭니다.
2. **Add file → Upload files**를 누르고 폴더 안의 파일 6개를 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**로 가서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://내아이디.github.io/talkstep/` 주소가 생깁니다.

### 방법 C. 컴퓨터 없이 아이폰만으로 (GitHub Pages)

1. 받은 `talkstep.zip`을 아이폰 **파일** 앱에서 꾹 눌러 **압축 해제**합니다. `talkstep` 폴더가 생깁니다.
2. 사파리에서 `github.com`에 로그인합니다.
3. 오른쪽 위 **+** → **New repository**를 누릅니다. 이름은 `talkstep`, 공개 범위는 **Public**으로 하고 **Create repository**를 누릅니다.
4. 만들어진 화면에서 **uploading an existing file** 링크를 누릅니다.
5. **choose your files**를 누르고 → 파일 앱 → `talkstep` 폴더 → 오른쪽 위 **선택**을 누르고, 파일을 **모두** 고른 뒤 **열기**를 누릅니다.
6. 아래쪽 **Commit changes**를 누릅니다.
7. 저장소 화면의 **Settings** → 왼쪽 메뉴 **Pages** → Branch를 **main**, 폴더를 **/(root)**로 고르고 **Save**를 누릅니다.
8. 1~3분 뒤 `https://내아이디.github.io/talkstep/` 주소로 사파리에서 열립니다.
9. 사파리 **공유 버튼(□↑)** → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

> 처음 마이크 버튼을 누르면 사파리가 마이크와 음성 인식 허용을 물어봅니다. 둘 다 **허용**하세요.
> 소리가 안 나면 아이폰 옆면의 **무음 스위치**를 꺼 주세요.

### 휴대폰 홈 화면에 앱처럼 설치하기

- **아이폰 (사파리)**: 앱 주소 열기 → 아래쪽 **공유 버튼** → **홈 화면에 추가**
- **안드로이드 (크롬)**: 앱 주소 열기 → 오른쪽 위 **⋮** → **홈 화면에 추가** 또는 **앱 설치**

설치하면 주소창 없이 진짜 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 없어도 동작합니다.

## 4. 내용 고치기 / 대화 추가하기

`index.html`을 **메모장**(윈도우)이나 **텍스트 편집기**(맥)로 엽니다. 무료 프로그램인 VS Code를 쓰면 더 편합니다.

### 대화 하나는 이렇게 생겼습니다

```js
{id:"d1a", cat:"daily", lv:1, title:"Meeting a New Neighbor", ko:"새 이웃과 첫 인사", partner:"Emma",
 situ:"복도에서 옆집에 새로 이사 온 엠마(Emma)를 만났어요.",
 turns:[
  T("Hi! I'm Emma.",                  // ① 상대가 하는 말 (영어)
    "안녕하세요! 저는 엠마예요.",         // ② 해석
    "반갑다고 인사해 보세요.",            // ③ 학습자에게 주는 미션 (한국어)
    ["Nice to meet you, Emma."],      // ④ 모범답안 (여러 개 가능)
    [["nice to meet you|glad to meet you","만나서 반가워요"]]  // ⑤ 꼭 들어가야 할 핵심 표현
  ),
  ...
 ]},
```

- `cat`: `daily`(생활), `business`(비즈니스), `travel`(여행) 중 하나를 씁니다.
- `lv`: `1`(초급), `2`(중급), `3`(고급) 중 하나를 씁니다.
- `id`: 다른 대화와 겹치지 않는 아무 영문 이름이면 됩니다. 예: `t1c`
- ⑤ 핵심 표현은 `|`로 여러 표현을 허용합니다. 학습자가 모범답안과 다르게 말해도 핵심 표현이 들어 있고 문법이 맞으면 "잘했어요"로 통과합니다.
- 기존 대화 하나를 통째로 복사해서 붙여 넣고 글자만 바꾸는 방법이 가장 안전합니다. 쉼표(`,`)와 괄호 짝이 맞는지 꼭 확인하세요.
- 수정한 뒤 다시 배포할 때는 `sw.js` 파일의 `talkstep-v2`를 `talkstep-v3`처럼 숫자만 올려 주세요. 그래야 이미 설치한 사용자에게도 새 내용이 보입니다.

## 5. 수익화 방법 (모두 합법적인 방법)

`index.html` 맨 위쪽의 `CONFIG` 부분만 바꾸면 됩니다.

```js
const CONFIG = {
  premiumLevels: [],                 // 유료로 잠글 레벨
  unlockCodes: ["TALKSTEP-VIP"],     // 구매자에게 줄 잠금해제 코드
  buyUrl: "",                        // 내 판매 페이지 주소
  premiumPrice: "9,900원 (평생 이용)",
  adHtml: ""                         // 하단 광고/홍보 영역
};
```

### ① 프리미엄 잠금 (부분 유료화) — 가장 추천

초급은 무료로 풀어 사용자를 모으고, 중급·고급은 유료로 파는 방식입니다.

1. `premiumLevels: [2, 3]`으로 바꿉니다. 중급과 고급에 🔒 표시가 생깁니다.
2. `unlockCodes`에 나만 아는 코드를 넣습니다. 예: `["SPRING-2026-A7K"]`
3. 판매 페이지를 만듭니다. **크몽, 탈잉, 네이버 스마트스토어(디지털 상품), Gumroad** 같은 곳을 쓸 수 있습니다.
   - 상품 설명: "TalkStep 영어회화 프리미엄 이용권 (중급·고급 대화 12개 + 이후 추가되는 대화)"
   - 구매 후 안내 메시지에 잠금해제 코드를 적어 두면 구매자에게 코드가 전달됩니다.
4. 그 판매 페이지 주소를 `buyUrl`에 넣습니다.

> ⚠️ 알아 둘 점: 이 코드 방식은 간단한 대신, 코드를 아는 사람끼리 공유하면 막을 수 없습니다. 코드를 주기적으로 바꾸거나, 매출이 생기면 회원 로그인 방식으로 업그레이드하세요.

### ② 광고 / 내 상품 홍보

`adHtml`에 홍보 문구를 넣으면 홈과 결과 화면 아래에 나옵니다.

```js
adHtml: '1:1 화상 영어 첫 수업 50% 할인 → <a href="https://내-판매페이지" target="_blank">신청하기</a>'
```

- 내 전자책, 스터디 모임, 1:1 수업을 홍보하는 용도로 쓰면 좋습니다.
- **구글 애드센스**는 내 도메인(예: `talkstep.kr`)과 충분한 콘텐츠가 있어야 승인됩니다. 승인 후에는 애드센스가 준 코드를 `adHtml`이나 `<head>` 안에 넣으면 됩니다.

### ③ 그 밖의 수익 아이디어

- **B2B 판매**: 학원·어학원에 "수업용 회화 연습 도구"로 콘텐츠를 맞춤 제작해 판매합니다. 예: 그 학원 교재에 맞춘 대화.
- **분야별 확장팩**: 승무원 면접, 간호사 영어, 해외영업, 유학 인터뷰처럼 대상이 분명한 대화 묶음을 따로 판매합니다.
- **유튜브·블로그 연계**: 대화 하나를 영상이나 글로 소개하고 앱 링크로 유입시킵니다.

### 법적으로 꼭 지킬 것

- **대화 내용은 직접 쓴 것만 사용하세요.** 시중 교재나 다른 앱의 문장을 그대로 베끼면 저작권 침해입니다. 이 앱의 18개 대화는 새로 작성한 내용입니다.
- 유료로 팔면 **사업자등록**(간이과세자도 가능)과 **통신판매업 신고**가 필요할 수 있습니다. 크몽처럼 플랫폼을 통해 팔면 플랫폼 안내를 따르세요.
- "100% 원어민 실력 보장"처럼 **과장 광고는 하지 마세요.** 표시광고법에 걸릴 수 있습니다.
- 학습 기록은 사용자 기기 안에만 저장되고 서버로 보내지 않습니다. 나중에 회원가입을 붙이면 **개인정보처리방침**을 꼭 만들어야 합니다.

## 6. 자주 묻는 질문

**Q. 마이크 버튼을 눌러도 안 돼요.**
크롬(PC·안드로이드)이나 사파리(아이폰)를 쓰고, 처음 물어볼 때 마이크를 **허용**해 주세요. 파일을 더블클릭해서 연 경우나 일부 미리보기 화면에서는 마이크가 막힐 수 있습니다. 이때는 인터넷에 배포한 주소(https)로 열어 주세요.

**Q. 소리가 안 나요.**
휴대폰 무음 모드를 끄고, 대사 옆의 **듣기** 버튼을 눌러 보세요. 브라우저는 사용자가 한 번 화면을 누른 뒤에야 소리를 냅니다.

**Q. 기록이 사라졌어요.**
기록은 그 기기, 그 브라우저에만 저장됩니다. 브라우저 방문 기록이나 데이터를 지우면 함께 사라집니다.
