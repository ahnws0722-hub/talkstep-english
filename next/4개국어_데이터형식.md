# TalkStep 4개국어 문장 데이터 형식

문장 하나를 **영어 → 일어 → 중국어 → 한국어** 순서로 보여 주고 읽어 줍니다. 데이터는 `index.html`의 `2-1) 4개국어 문장` 부분에 있습니다.

```js
L4("Hello.", {enK:"헬로우.", ja:"こんにちは。", jaK:"곤니치와.", zh:"你好。", py:"Nǐ hǎo.", zhK:"니하오.", ko:"안녕하세요."});
L4("Nice to meet you.", {enK:"나이스 투 밋 유.", ja:"はじめまして。", jaK:"하지메마시테.", zh:"很高兴认识你。", py:"Hěn gāoxìng rènshi nǐ.", zhK:"헌 까오싱 런스 니.", ko:"만나서 반가워요."});
```

| 키 | 내용 |
|---|---|
| (첫 칸) | 영어 문장. `T(...)`의 상대 대사(첫 칸) 또는 모범답안 첫 번째와 **글자 하나까지 똑같이** |
| enK | 영어 한글 발음 |
| ja | 일본어 |
| jaR | 일본어 읽기(히라가나). **한자가 있을 때만** 넣고, 없으면 생략 |
| jaK | 일본어 한글 발음 |
| zh | 중국어(간체, 표준중국어) |
| py | 병음(성조 표시) |
| zhK | 중국어 한글 발음 |
| ko | 한국어 |

## 매주 월요일 새 대화를 넣을 때
1. 기존처럼 `SCENARIOS`에 새 대화(`T(...)` 5턴)를 추가합니다.
2. 5턴 × (상대 대사 + 모범답안 첫 번째) = **10문장**을 모두 `L4(...)`로 추가합니다. 위치는 `/* t3b */` 묶음 뒤, `checkLang4` 앞입니다.
3. `sw.js`의 `VER`를 하나 올립니다. 예: v8 → v9
4. 빠진 문장이 있으면 카드에 "일어·중국어 문장은 준비 중이에요"가 뜨고, 브라우저 콘솔에 빠진 목록이 나옵니다.

## 음성
- 브라우저 기본 음성(Web Speech API)을 씁니다: en-US, ja-JP, zh-CN, ko-KR. 비용은 없습니다.
- 기기에 그 언어 음성이 없으면 그 줄은 건너뛰고 한국어 안내를 보여 줍니다. 아이폰에서는 설정 › 손쉬운 사용 › 음성 콘텐츠(읽기 및 말하기) › 음성에서 추가할 수 있습니다.
- 줄마다 따라 말할 시간: 자동(문장 길이에 맞춤) / 2초 / 4초 / 6초. 설정에 저장됩니다.
